5. UI Templates

Import Samples~/StarterUI via Package Manager (Window → Package Manager → Imasu Steamworks → Samples → Import). Each script is a minimal MonoBehaviour that exposes public inspector slots (TMP_Text, RawImage, Button). Drag your UI elements onto them — no code required. Everything lives in namespace Imasu.Steamworks.Templates.

5.1 SteamUserBadge

Shows a player's Steam avatar + name + online state.

  • Slots: RawImage avatar, TMP_Text nameText, ulong steamId.
  • Pulls: AvatarCache.Get(id) + AvatarCache.AvatarLateAssign for lazy loading.
  • Use in: waiting room rows, scoreboard, friend lists.

5.2 LobbyCodeDisplay

Shows the current lobby's short code and copies it to the clipboard on click.

  • Slots: TMP_Text codeText (the clickable box), optional TMP_Text statusText.
  • Pulls: SteamLobbyManager.currentLobby / LobbySettings.code.

5.3 PlayerListUI

Builds a list of lobby members from SteamLobbyManager.members (or networked VoicePlayers in non-Steam sessions).

  • Slots: RectTransform rowParent, optional row prefab.

5.4 InviteButton

Sends a lobby invite for a chosen friend; falls back to the native Steam overlay.

  • Slots: Button button, ulong friendSteamId, optional TMP_Text feedback.
  • Pulls: Lobby.InviteFriend(id).

5.5 VoiceIndicator

Colors a UI ring by a player's voice state.

  • Slots: Image ring.
  • Reads: VoicePlayer.isSpeaking (green), micState Failed (red), else grey.

5.6 HostSetupForm

Binds a ImasuSteamworksConfig to a host-setup UI (max/min players, map, security, voip).

  • Slots: inputs/dropdowns per field.
  • Reads/writes: ImasuSteamworksMaster.Config.
