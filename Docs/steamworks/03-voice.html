3. Voice

Voice capture and codec are Steam's (SteamUser). The transport is Mirror — compressed voice frames go over the unreliable channel, so it works over both Steam P2P and LAN/KCP. Steam must be running to capture or decode; on non-Steam sessions the Push-to-Talk button is hidden and the waiting room shows "Voice requires Steam."

3.1 Fixed vs. Range

ModeControl Center settingBehaviour
FixeduseDistanceAttenuation = OFFNo distance dropoff. Every speaker is heard at full volume regardless of distance. Players only adjust the global VOIP volume. Best for small teams / LAN.
RangeuseDistanceAttenuation = ONLogarithmic rolloff between voipMinDistance and voipMaxDistance (a 3D AudioSource). Walk away → quieter → silent.

3.2 Who controls distance? The host.

Players do not change distance. The host sets it in the Control Center (voipMaxDistance), which is also advertised as the lobby's voice range. The host can still override per-session on the Game Setup screen.

3.3 Per-user VOIP volume

Because mics vary in loudness, each player tunes how loud others are: Settings → Audio → VOIP Volume (0–2×, default 1.0). The gain is applied to each remote player's AudioSource.volume. It does not affect distance.

3.4 Voice in the UI

  • Push-to-Talk (waiting room) — hold/toggle; hidden when Steam is off.
  • Waiting room rows — show mic-live / talking state and a sent/received KB line.
  • Scoreboard (hold Tab) — ring avatars: green = talking, red = mic confirmed failed, grey = unknown, plus ping.
  • Voice HUD — in-match indicator.
