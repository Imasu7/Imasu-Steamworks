6. Testing & Smoke Players

6.1 The smoke-test build

A prebuilt Windows player ships via GitHub Releases (HiddenDevHDRP-Smoke.zip). It's the easiest way to play-test without Unity or git. The unzipped folder (Builds/LocalTestSmoke/) is kept locally for devs and is not committed; the zip is versioned via Git LFS and refreshed automatically by a pre-push hook. 

HiddenDevHDRP.exe                # normal play
HiddenDevHDRP.exe --smoke=ui        # verify UI + local KCP host
HiddenDevHDRP.exe --smoke=lan-flow  # verify Leave Lobby + Start Match
HiddenDevHDRP.exe --smoke=steam-host# verify Steam lobby create + host

6.3 Multi-machine LAN test

  1. Host: Game Setup → uncheck "Use Steam networking" → Create Lobby & Host.
  2. Client: Join Game → type the host's IP (or use Browse → LAN SERVERS).
  3. Start Match → both reach the map. (Windows doesn't loop UDP broadcasts back, so LAN discovery needs two real machines.)

6.4 Building the smoke player

Unity.exe -batchmode -quit -projectPath <proj> \
  -executeMethod Hidden.LocalTest.Editor.LocalTestSceneBuilder.BuildSmokePlayer

6.5 Rebuilding the game scenes/prefabs

Unity.exe -batchmode -quit -projectPath <proj> \
  -executeMethod Hidden.LocalTest.Editor.ProductionSceneBuilder.BuildAll

Regenerates MainMenu / WaitingRoom / Game / Warehouse scenes, the ImasuSession and DummyPlayer prefabs, and HDRP materials.
