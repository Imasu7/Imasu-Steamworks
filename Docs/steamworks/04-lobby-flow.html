4. Lobby Flow

MainMenu (offline) → Game Setup → WaitingRoom (online) → Game (match)

4.1 Host

  1. Host Game → Game Setup: server name, max players, map, voice distance, security.
  2. Use Steam networking checkbox: ON = Steam lobby + Steam P2P transport; OFF = LAN/KCP host (no Steam). Hidden when allowNonSteamServers is off.
  3. Create Lobby & Host → Waiting Room. Share the lobby code (click to copy).
  4. Start Match (host only) → everyone loads the chosen map. Blocked until members ≥ minPlayers.

4.2 Join

  • Code — 7-char short code (raw lobby IDs also accepted).
  • IP / hostname — LAN join (e.g. 192.168.1.20, localhost). Blocked when non-Steam is disabled.
  • Browse Servers — Steam public lobbies (filtered by a marker key so foreign Spacewar lobbies never show) merged with a LAN SERVERS section from UDP discovery.
  • Invites — searchable friend list (hover a row to reveal the blue Invite button) and a native Steam overlay picker.

LAN tunables (Control Center → Modules → LAN when the addon is installed): the discovery port (default 47777), Active Discovery (periodic probe vs. passive listen), and how long a discovered server stays listed without a reply (Max Stale). Settings persist per-project (PlayerPrefs) and apply the next time the browser opens or a host advertises. LAN servers only appear when allowNonSteamServers is on.

4.3 minPlayers enforcement

With minPlayers = 1 (default) the host can start solo. Set it higher and the host is blocked with a clear "Need N players to start" message in the waiting room until enough players are connected.

4.4 Leaving

  • Leave Lobby — full teardown in both Steam and non-Steam modes; everyone returns to the main menu.
  • Pause → Quit to Menu — stops the session and loads the offline scene.
  • Pause → Back to Lobby (host only) — pulls the whole party back to the waiting room.
