Imasu Steamworks

A reusable Steam multiplayer stack for Unity 6: Steam lobbies, Mirror transport via FizzyFacepunch, LAN/KCP fallback, distance-based voice, and a single configuration window — the Imasu Steamworks Control Center. Game-agnostic: add it to any project.

What you get

  • One config asset (ImasuSteamworksConfig) — every tunable in one place, edited from Imasu → Steamworks Control Center.
  • Drag-and-drop session object (ImasuSession) — network manager, Steam, transport, lobby, and UI all on one GameObject.
  • Steam lobbies with short join codes, invites, server browser, and LAN discovery.
  • Voice — Steam capture/compression over Mirror, with Fixed (no dropoff) or Range (min/max) modes and a per-user VOIP volume.
  • Runtime-built UI — main menu, game setup, waiting room, pause, scoreboard, settings.
  • Copy-paste UI templates — grab Steam names, avatars, lobby codes, voice state with one script.
  • Smoke-test player — a prebuilt .exe for non-Unity play-testers (GitHub Releases).

Quick start (3 lines)

  1. Add the package to your project (see Getting Started).
  2. Open Imasu → Steamworks Control Center and create the config asset.
  3. Run the project — the ImasuSession object drives everything.

Non-Unity testers: grab the latest HiddenDevHDRP-Smoke.zip from GitHub Releases, unzip, and run HiddenDevHDRP.exe.

Not a Unity dev?

You don't need Unity to play-test. The smoke build is a normal Windows game. Host a game (Steam or LAN), share the lobby code, and play. For hosting a LAN game without Steam, use the "Use Steam networking" checkbox on the Game Setup screen (only visible when Allow non-Steam servers is enabled in the Control Center).
