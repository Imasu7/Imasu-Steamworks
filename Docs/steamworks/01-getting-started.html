1. Getting Started

1.1 Add the package

The package is a UPM package. Two ways to add it:

Option A — local folder (while developing)

// Packages/manifest.json
"dependencies": {
  "com.imasu.steamworks": "file:Packages/com.imasu.steamworks",
  "com.mirrornetworking.mirror": "file:Packages/com.mirrornetworking.mirror"
}

Option B — git URL (for other developers)

"com.imasu.steamworks": "https://github.com/Imasu7/Hidden-Dev-HDRP.git?path=Packages/com.imasu.steamworks"
"com.mirrornetworking.mirror": "file:Packages/com.mirrornetworking.mirror"
Mirror is vendored as an embedded package (com.mirrornetworking.mirror) because the official Mirror repo ships a .unitypackage, not a package.json. Copy it next to this package.

One global config, not per-map. A single ImasuSteamworksConfig asset drives the whole project. 1.3 The ImasuSessionManager object

Every multiplayer scene contains a ImasuSessionManager prefab instance (the required per-scene contract — a map without it won't appear in the catalog). Only the first one survives at runtime (DontDestroyOnLoad); later scene instances self-destroy. In this project the ProductionSceneBuilder creates it; in a new project you add it manually:

  1. Open Imasu → Steamworks Control Center.
  2. Pick your config in the Active Config field at the top (the choice is saved and auto-applied to Session Managers in open scenes). If you have none yet, click Create New Config.
  3. Open the scene and click Add Session Manager to Scene in the Control Center bottom bar — it instantiates the prefab for you.
  4. Add these components to that same GameObject (all auto-wire via FindFirstObjectByType if left blank): ImasuNetworkManager, FizzyFacepunch, KcpTransport, SteamManager, SteamLobbyManager, ImasuSessionUI, ImasuSteamworksMaster, SpawnManager.
  5. Place Player Spawns (Control Center → Spawns & Teams → Add Spawn Point / Area) — players spawn there, team-filtered and anti-clump.
  6. Set ImasuNetworkManager.playerPrefab to your networked player prefab.

1.4 First run

Press Play with Steam running. You should land on the main menu:

  • Join Game — enter a 7-character code, an IP/hostname, or browse Steam + LAN servers.
  • Host Game — pick a Gamemode then its Map (both from the config's catalog), set name, max players, voice distance, security; optionally disable Steam networking.
  • Settings — display, audio, controls (incl. mouse sensitivity and per-user VOIP volume).
  • ESC closes any open modal (invite list, dropdown popups) — it never navigates between screens.

In-match, the host opens the pause menu and uses Change Map to move the whole party to another map from the config's catalog.

Everything beyond here is configurable — see Control Center for every field.
