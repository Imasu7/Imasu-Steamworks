7. Troubleshooting

Steam isn't initialized

Symptoms: menu shows "Steam: not initialized", no lobbies, no invites, Push-to-Talk hidden.

  1. Is Steam running and logged in? Steam must be open.
  2. Is steam_appid.txt at the project root with 480?
  3. Does the App ID match ImasuSteamworksConfig.steamAppId (Control Center)?

Avatars are blank or upside-down

Friend avatars download lazily. The invite list re-inits rows so they fill on their own (no typing needed). If blank after ~15 s, check the log for [AvatarCache] No avatar for <id> — that player may genuinely have no avatar.

Upside-down avatars in the waiting room / scoreboard (not the invite list) mean the vertical flip is only applied to invite rows — move it to AvatarCache texture creation.

Start Match does nothing

  • Not enough players: check minPlayers (Control Center) — the waiting room shows "Need N players".
  • Non-Steam host: the map must be selected in Game Setup (it's copied to matchScene at create time).
  • Log shows StartMatch needs matchScene set → configure maps[] or matchScene.

Can't connect / LAN server not listed

  • Windows doesn't loop UDP broadcasts back — LAN discovery needs two machines.
  • Firewall blocking UDP 7777? Allow the exe.
  • "Allow non-Steam servers" is off (Control Center → Debug) → LAN paths are hidden. This is expected.

Invites "Retry" / amber

The lobby may be invite-only, or Steam rate-limited. The invite result is logged with the friend's name + SteamID in Player.log.
