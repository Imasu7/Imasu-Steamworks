2. The Control Center — every setting

Open Imasu → Steamworks Control Center. This is the single window for everything: it edits the shared ImasuSteamworksConfig asset, and the Apply Active Config to Session Managers button pushes those values into the live components (SteamManager, FizzyFacepunch, KcpTransport, ImasuNetworkManager). No hunting through six scripts.

2.0 One global config, not per-map

There is one ImasuSteamworksConfig asset per project. The Active Config field at the very top of the window shows which asset is in use; picking a different asset switches the whole project to it — the choice is saved and auto-applied to every ImasuSessionManager/ImasuSteamworksMaster in the open scenes. Click Create New Config for a fresh empty asset, or Duplicate Template to copy the package's StarterConfig sample. Maps are not configs — they are scene names listed inside gameModes[] → maps[], each optionally overriding the player cap. The ImasuSteamworksMaster.config field you see in the Inspector is only an instance mirror of that one asset — don't edit it per scene. At runtime only the first Session Manager survives (DontDestroyOnLoad singleton), so the config is global across all scenes.

2.1 Addon kill-switch

The big Imasu Steamworks enabled toggle at the top of the window is the one-click kill-switch. OFF suppresses the whole addon: no hard errors, no Steam init, host/join/start are blocked with a soft note, and the game runs as single-player. Untick the ImasuSteamworksMaster component in the Inspector for a per-scene override. You can also never run without a config: if the master has no config wired, sessions are hard-blocked with a red banner pointing you back here.

2.2 The tabs (what lives where)

TabWhat you edit there
Project Scenes & LobbymainMenuScene / lobbyScene (Mirror offline/online scenes), the Session defaults (maxPlayers, minPlayers, lobbyName, security, lobbyCodeLength), a Steam (advanced) foldout (steamAppId, requireSteam), plus the Sync Build Settings button.
Gamemodes & MapsThe map catalog — add / rename / remove gamemodes and their maps. A map is a display name + a scene (typed or picked from the scene list). Each gamemode has optional overrides (Session / Voice / Player Mover / Transport) ticked per-field, with a live Effective summary (map → gamemode → global).
Spawns & TeamsSpawns detected in the open scene with a per-spawn team popup, plus the team config edited inline (min separation, team count presets 1/2/4, per-team name/color/spawn ID). No need to open the ImasuTeamConfig asset.
ModulesOptional addons (Voice / LAN / Dedicated / Character). Installed addons can be removed or updated; uninstalled ones have an Install from GitHub button (git URL + scoped tag — no clipboard paste). Embedded packages show as built-in. Installed addons draw their settings inline here.
Detailed ConfigEvery raw field of the config asset — the advanced fallback. Changes commit on Enter / focus-lost, not per keystroke.

Because Host Setup and Pause → Change Map read the same catalog, a map added in the Gamemodes tab appears everywhere. When you add a map, the Control Center also auto-syncs it into the classic Build Settings and the active Unity 6 Build Profile, so it works in both Play Mode and player builds — no manual profile digging. The runtime Host dropdown also refreshes automatically after a config change (it watches a catalog version, so you don't need to reload the scene).

2.9 Apply & validation

  • Apply Active Config to Session Managers — pushes the Active Config into every ImasuSessionManager/ImasuSteamworksMaster in the open scenes and marks them dirty. This also happens automatically whenever you change the Active Config or edit a field in a purpose tab (throttled so it doesn't hammer the scene mid-slider-drag).
  • Add Session Manager to Scene — instantiates the ImasuSessionManager prefab into the open scene.
  • Validation — the window flags any mainMenuScene / lobbyScene / map scene missing from Build Settings, with a Sync Build Settings button to add them (classic list and active Build Profile).
  • Validate Maps — opens each map scene (additively) and checks it contains an ImasuSessionManager + at least one spawn. Failing maps are listed in the Project Scenes & Lobby and Gamemodes tabs. A valid map scene is a runnable multiplayer map.
  • Open Offline Docs — opens this site (Docs/index.html).
Host map list stale? If you added a map to the config but the Host Setup dropdown still shows the old list, run Imasu → Steamworks → Sync Session Prefab to Config (or the Apply Active Config to Session Managers button with the Session Manager scene open, then save the scene). This rebuilds the baked catalog inside the ImasuSessionManager prefab.
