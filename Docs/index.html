Imasu — Unity modules

Reusable, game-agnostic Unity packages developed together. Each module has its own documentation area and can be installed on its own.

Imasu Steamworks (com.imasu.steamworks)

Steam multiplayer for Unity 6: lobbies, Mirror transport, distance voice, LAN fallback, and the Control Center. Add the ImasuSession object to any scene to make it multiplayer.

Steamworks documentation →

  • Addons: Voice (com.imasu.steamworks.voice), LAN (com.imasu.steamworks.lan), Dedicated Servers (planned).
  • Installing/removing addons from GitHub from inside the Control Center is planned (Addon Manager).

Imasu Character Controller (com.imasu.character)

An advanced first-person character controller (Opsive-level ambition): movement, inventory, weapons & hands, health/stamina, footstep controller, a stress state system, DAZ character customization, and multiplayer support as an optional addon.

Character Controller docs →

Planning stage — not yet installable. The feature list is a roadmap, not a final spec.

How modules relate

com.imasu.character.multiplayer → com.imasu.character + com.imasu.steamworks
com.imasu.steamworks.voice/lan/dedicated → com.imasu.steamworks
com.imasu.steamworks → com.mirrornetworking.mirror (vendored)

Cross-module communication is always through public interfaces (IVoiceMember, ILanDiscovery, ICharacterNetworkAdapter, IImasuModule). com.imasu.character depends on nothing Imasu — it works standalone for single-player games.
